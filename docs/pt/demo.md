# Demo do Papyrus

Teste o leitor antes de entrar nos detalhes de implementacao. Use o painel de configuracao para trocar engines, temas, opcoes da UI e uploads locais.

<DemoFrame />

## O que testar

- Carregar o PDF incluido e navegar pelas paginas.
- Alternar entre PDF, PDF Rust/WASM, EPUB, TXT, CBZ e CBR quando suportado pelo demo web.
- Testar busca, miniaturas, temas, zoom, anotacoes e selecao de texto.
- Abrir o leitor em um modal maior com **Abrir exemplo interativo**.

O demo e gerado a partir de [`examples/web/App.tsx`](https://github.com/solrachix/Papyrus/blob/main/examples/web/App.tsx), usando os mesmos contratos de pacotes descritos nos guias.
