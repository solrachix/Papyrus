# Papyrus Demo

Try the reader before reading the implementation details. Use the configuration panel to switch document engines, themes, UI options, and local uploads.

<DemoFrame />

## What to try

- Load the bundled PDF and navigate through pages.
- Switch between PDF, Rust/WASM PDF, EPUB, TXT, CBZ, and CBR flows where supported by the browser demo.
- Test search, thumbnails, themes, zoom, annotations, and text selection.
- Open the reader in a larger modal with **Abrir exemplo interativo**.

The demo is built from [`examples/web/App.tsx`](https://github.com/solrachix/Papyrus/blob/main/examples/web/App.tsx), so it exercises the same package contracts documented in the guides.
